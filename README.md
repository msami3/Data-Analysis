# Data Analysis Projects

This repository contains two separate data analysis projects:

1. Divvy Daily Ride Data Analysis (F#)
2. UIC Course Grade Analysis (C++)

## 1. Divvy Daily Ride Data Analysis

### Project Description

This F# program analyzes Divvy daily ride data, providing various statistics and visualizations about ride patterns, user demographics, and ride durations.

### Features

- Parses Divvy ride data from a given input file
- Calculates and displays:
  - Total number of riders
  - Percentage of riders identifying as male or female
  - Average age of riders
  - Distribution of ride durations
  - Histogram of ride start times

### Usage

1. Ensure you have F# installed on your system.
2. Run the F# program using your preferred F# compiler or runtime.
3. When prompted, enter the filename of your Divvy ride data file.

## 2. UIC Course Grade Analysis

### Project Description

This C++ program provides a set of utilities for analyzing course grade data from the University of Illinois at Chicago (UIC). It includes functions for parsing course data, calculating DFW rates, and finding courses based on various criteria.

### Features

- Parses course data from CSV format
- Calculates DFW (D, F, Withdraw) rates for courses, departments, and colleges
- Computes grade distributions for courses, departments, and colleges
- Allows searching for courses by course number or instructor name
- Supports analysis across multiple departments and colleges

### Usage

1. Ensure you have a C++ compiler installed on your system.
2. Compile the C++ file using your preferred compiler.
3. Link the compiled object file with your main program that uses these utilities.

## Installation

To use these projects:

1. Clone this repository to your local machine.
2. For the F# project, ensure you have F# installed. You can download it from the [official F# website](https://fsharp.org/).
3. For the C++ project, ensure you have a C++ compiler installed on your system.
